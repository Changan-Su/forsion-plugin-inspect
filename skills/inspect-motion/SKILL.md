# 检视台检视动作(`.motion.json`)

按 `F` 之后发生三件事:**切刀(deploy)→ 检视(inspect)→ 收刀(holster)**。

**你只能改中间那段。** 切刀和收刀是内置的,因为它们要接得住任意时长的检视轨 —— 让每份动作文件自己处理入场/退场,写十份就要写十遍。

## 坐标系(先读这段,不然数全是瞎猜的)

第一人称手持视角。相机在原点朝 **−z** 看,单位≈**米**,视场角 65°:

- `x`:**正 = 画面右**。持刀手在右边,所以刀的 x 基本恒正。
- `y`:**正 = 上**。−0.4 大约是画面下缘偏上一点。
- `z`:**负 = 往前(离眼睛远)**。刀常年在 `-0.9 ~ -1.05`,再近就怼脸,再远就变小。
- 旋转是**欧拉角、弧度**,顺序 XYZ。

### 两条轨,分工不同

| 轨 | 动什么 | 想象成 |
| --- | --- | --- |
| `hand` | 手腕挂点(**手和刀一起**) | 手臂把整套东西搬到哪儿 |
| `weapon` | 刀**相对握把**的转动 | 刀在掌心里怎么翻 |

**手不跟着刀转**,这是这个插件的结构闸:让刀翻跟头请只动 `weapon`,动 `hand` 会把手一起翻过去(看着像手腕断了)。

### 必须知道的三个锚点

```jsonc
// 静置位 REST —— 斜横在画面右下,刀尖朝左上约 30°。动作**首帧和末帧都用它**,
// 否则切刀刚结束就瞬移一下,收刀开始又瞬移一下(两处都很明显)。
{ "p": [0.54, -0.40, -1.02], "r": [0.16, -0.34, 1.02] }

// 刀在握把上的零位 WEAPON_REST —— weapon 轨的首帧末帧用它。
{ "p": [0, -0.25, 0], "r": [0, 0, 0] }

// 举到眼前看刀面,大致是这一带(不是硬规定,给你个量级参考)
{ "p": [0.34, -0.10, -0.95], "r": [0.10, -0.20, 0.14] }
```

`weapon` 的 `p` 基本永远写 `[0, -0.25, 0]`:那是握把在归一化后模型里的位置,挪它等于让刀脱手。

## 字段表

```jsonc
{
  "name": "慢转一圈",          // 下拉里显示的名字;省略 = 文件名
  "hand":    [ { "t": 0, "p": [x,y,z], "r": [x,y,z] }, … ],  // 必填,≥2 帧
  "weapon":  [ { "t": 0, "p": [x,y,z], "r": [x,y,z] }, … ],  // 可选,省略 = 刀在手里不动
  "handles": [ { "t": 0, "a": 0, "b": 0 }, … ]               // 可选,只有蝴蝶刀吃这条
}
```

- `t` 是**秒**,从 0 起,**必须严格递增**(相等会让插值除以 0,刀会当场消失);
- **三条轨各自都要至少两帧**(不是只有 `hand`):`weapon` 或 `handles` 只写一帧,整份文件会被拒收。
  某条轨没什么要动的就**整条省略**,别写单帧占位;
- **总时长 = 最后一帧的 `t`**,没有 duration 字段。上限 30s、400 帧;
- 每段之间是 **easeInOut**(两头慢中间快)。想要匀速就多打几个等距关键帧,别指望有 easing 字段;
- `handles.a` / `handles.b` 是蝴蝶刀两片柄的转角(弧度),`0` = 完全张开。
  ⚠️**末帧必须回到 `0`(或 2π 的整数倍)**:检视一结束就切回内置的静置/收刀姿态,而那两条把
  `handles` 当 `{a:0,b:0}` —— 你若以「合刀」(`a: π`)收尾,刀柄会在结束那一瞬间**啪地弹开 180°**。

## ⚠️ 整圈必须让角度**累加**过 2π

关键帧之间是**逐轴线性插值**,不是四元数最短弧。所以:

```jsonc
{ "t": 0,   "r": [0, 0,     0] },
{ "t": 1.6, "r": [0, 6.283, 0] }   // ✅ 6.283 = 2π,刀真的转满一圈
```

```jsonc
{ "t": 0,   "r": [0, 0, 0] },
{ "t": 1.6, "r": [0, 0, 0] }       // ❌ 写"转回原位"= 根本没转
```

转两圈就写 `12.566`。同理,**下一帧要接着上一帧的绝对角写**,别每帧都归零 —— 归零那一帧会把刀倒着转回去。

## 可直接抄的完整示例

```json
{
  "name": "慢转一圈",
  "hand": [
    { "t": 0,    "p": [0.54, -0.40, -1.02], "r": [0.16, -0.34, 1.02] },
    { "t": 0.42, "p": [0.36, -0.12, -0.96], "r": [0.10, -0.22, 0.16] },
    { "t": 1.90, "p": [0.34, -0.08, -0.94], "r": [0.08, -0.18, 0.14] },
    { "t": 2.40, "p": [0.40, -0.18, -0.98], "r": [0.12, -0.26, 0.48] },
    { "t": 3.00, "p": [0.54, -0.40, -1.02], "r": [0.16, -0.34, 1.02] }
  ],
  "weapon": [
    { "t": 0,    "p": [0, -0.25, 0], "r": [0, 0,     0] },
    { "t": 0.42, "p": [0, -0.25, 0], "r": [0, 0.30,  0] },
    { "t": 1.90, "p": [0, -0.25, 0], "r": [0, 6.583, 0] },
    { "t": 2.40, "p": [0, -0.25, 0], "r": [0, 6.283, 0] },
    { "t": 3.00, "p": [0, -0.25, 0], "r": [0, 6.283, 0] }
  ]
}
```

读法:手把刀端到眼前 → 刀在掌心里绕竖轴转满一圈(`0 → 6.583 → 6.283`,冲过头一点再回落,这是「甩」的手感)→ 手放回静置位。

蝴蝶刀想让两片柄翻起来,再加:

```json
"handles": [
  { "t": 0,   "a": 0,      "b": 0 },
  { "t": 0.9, "a": 6.283,  "b": -6.283 },
  { "t": 1.8, "a": 12.566, "b": -12.566 },
  { "t": 3.0, "a": 12.566, "b": -12.566 }
]
```

## 装到哪儿 · 怎么验

1. 写进插件**工作文件夹**:设置 → 插件 → 检视台,卡片第一行就是**绝对路径**,右边有「打开文件夹」。
   **让用户把那行路径贴给你,别猜** —— 用户可能用的是云端库,本地镜像在 `~/.forsion/Amadeus Cloud/`
   (dev 版 `~/.forsion-dev/…`)这样的**隐藏目录**;写到别处插件看不见,而且**不报任何错**,
   表现就是「做完了但用不了」。实在要猜,先把候选列给用户确认:
   `ls -d ~/.forsion*/"Amadeus Cloud" ~/Documents/*/`;
2. 用户在自己模型那一行的「**检视动作**」下拉里选中它;
3. 切到 Tangu Space、光标不在输入框里,**短按 `F`** —— 切刀 → **你这段** → 自动收刀;
4. 长按 `F` 的详情页上,「检视动作」那一栏会写着你的 `name`,能确认真的生效了;点一下模型可重播。

改完文件后重开一次设置页或详情页刷新缓存。

## 出错了怎么看

设置页那张卡会**逐条列出读不进来的文件和人话原因**(`hand 第 3 帧的 t 没有比上一帧大` 之类)。坏文件不会让画面变黑,插件会退回内置动作 —— 所以「按 F 一切正常但没用上我的动作」时,第一件事是去那张卡上看有没有报错行。

## 调参手感

- 一段完整检视 **2.5 ~ 5s** 最自然;短于 1.5s 像抽搐,长于 8s 用户会先按 Esc;
- 位置每帧变化别超过 0.3;想要「甩」的爆发力靠**缩短时间间隔**,不是靠拉大位移;
- 只想要慢动作:把现成示例每个 `t` 乘 1.5,姿态一个都不动。

## 相关

- 只想换颜色/刀型,不改动作:用技能 **检视台刀皮制作**(`.skin.json`)。
