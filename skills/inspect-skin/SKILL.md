# 检视台刀皮(`.skin.json` / `.glb`)

「检视台」= 在 Tangu Space 里按 `F`,当前对话模型化作一把刀在页面上被举起来耍两下(照 CS 的第一人称检视)。**刀皮就是这把刀长什么样**。

## 先搞清楚两种刀皮,别做错东西

| 你要做的 | 文件 | 你能不能亲手写 |
| --- | --- | --- |
| 换配色 / 换刀型(普通刀 ↔ 蝴蝶刀) | `<名字>.skin.json` | **能**,纯 JSON,这是你的主战场 |
| 换成一把真正的 3D 刀(自定义几何) | 用户给的 `.glb` / `.gltf` + 一份指向它的 `.skin.json` | 模型**写不出来**,但「把它用起来」是你的活 —— 见「用户丢来一个 .glb」一节 |

用户说「做一把刀皮」而没提模型文件时,一律做 `.skin.json`;**用户丢来一个模型文件让你「识别并应用」时,
也是写 `.skin.json`** —— 用 `model` 字段指向那个模型(第三节)。

## 装到哪儿(**先读这段,写错地方是本技能的头号失败**)

全部放进插件的**工作文件夹** —— 一个**笔记库内**的普通目录。

**唯一可靠的取路径方式:让用户打开 设置 → 插件 → 检视台,那张卡最上面一行就是绝对路径**
(右边有「打开文件夹」按钮,点了直接在访达里打开)。让用户把那行路径贴给你。

⚠️**绝对不要猜 `~/Documents/<库名>/检视台`。** 用户可能用的是**云端库**,它的本地镜像在
`~/.forsion/Amadeus Cloud/`(dev 版是 `~/.forsion-dev/Amadeus Cloud/`)——一个隐藏目录,
你猜不到;写到别处插件一个字都看不见,而且**不会报任何错**,表现就是「做完了但用不了」。

实在拿不到那行路径,先把候选列出来给用户确认,别赌:

```bash
ls -d ~/.forsion/"Amadeus Cloud" ~/.forsion-dev/"Amadeus Cloud" 2>/dev/null   # 云端库镜像
ls -d ~/Documents/*/                                                          # 本地库常见位置
```

拿到绝对路径后用你自己的写文件工具落盘即可,**不需要任何插件 API**;文件夹不存在就先建。
写完**一定要告诉用户去哪儿选**(见文末「装好之后」)——你写文件,选中那一下得他来点。

## `.skin.json` 字段表

```json
{
  "name": "霜刃",
  "knife": "standard",
  "primary": "#5ec8ff",
  "secondary": "#123a52"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 否 | 下拉里显示的名字。省略 = 用文件名(去掉 `.skin.json`) |
| `knife` | 否 | `standard`(普通刀,缺省)或 `butterfly`(蝴蝶刀,双柄可动,另有一套翻柄动画) |
| `primary` | **是** | 刀身主色,**必须是 `#rrggbb`**。`red`、`rgb()`、`hsl()` 一律拒收 |
| `secondary` | 否 | 刀柄/护手色。省略 = 自动用主色同色相压暗一档 |
| `model` | 否 | **库内 `.glb` / `.gltf` 的路径**(见下一节)。给了它就用这把真模型,`primary`/`secondary` 不再生效 |

`knife` **区分大小写**:写 `"Butterfly"` 会被当成不合规拒收(而不是悄悄降级成普通刀)。

## 用户丢来一个 `.glb` / `.gltf`,让你「用起来」

你写不出 3D 网格,但**把一个现成模型用起来是三行 JSON 的事** —— 这是 `.glb` 唯一能被 agent 接手的通道:

1. 确认那个模型文件**在工作文件夹里**(不在就先按上一节的路径把它挪进去);
2. 在**同一个文件夹**里写一份 `.skin.json`,用 `model` 指向它(路径是**库内相对路径**,不是绝对路径):

```json
{ "name": "我的刺刀", "model": "检视台/bayonet.glb" }
```

3. 告诉用户去 设置 → 插件 → 检视台,在自己模型那一行的「刀皮预设」里选中「我的刺刀」。

要点:
- `model` 只认 `.glb` / `.gltf` 结尾,写别的会被拒收并在设置页报错;
- 给了 `model` 就**不用写 `primary`**(导入的模型自带材质,颜色不生效);
- **朝向不用管**:模型任意尺度会被自动归一,朝向也会自动摆正(最长轴立起来当刀锋、最薄轴正对镜头,
  再按 `handle`/`grip`/`柄` 这类节点名把刀柄转到下面 —— 没有命名就按「厚的那半是刀柄」判)。
  Sketchfab / Blender 导出的模型多半躺在 X 轴上,原样装是横在半空的,这一步就是为它们做的;
- 万一某个模型摆正得不对(极少数比例怪异的),让用户在长按 F 的皮肤箱下半段选「✕ 不画手」,
  或者换一个模型 —— 目前没有手动改朝向的字段。
- 需要**比 2.8.1 更新的宿主**(2.8.1 发布版的 CSP 没放行 `amadeus-asset:` 的 fetch,症状是模型读不出来)。

**没有品质字段,也不要造一个。** 面板上那一栏「品质」如实对应当前会话的**思考档(Effort)**:`off`→消费级 …… `max`→非凡(金)。让文件声明品质等于允许伪造,插件会忽略任何多余字段。做旧程度、花纹号同理 —— 那些由模型 id 稳定推出,是「同一个模型永远是同一件藏品」的一部分。

## 配色怎么挑才不难看

刀身是**金属**(metalness 高),环境反射占了大半观感:

- 主色给**中等明度、饱和度别拉满**(`#5ec8ff` 好过 `#00d0ff`)—— 太亮的颜色在高光下会糊成一片白;
- 辅色比主色**暗两档**最稳,同色相或邻近色相;互补色只在你确实想要撞色时用;
- 想要「暗黑/哑光」观感就把两色都压到 `#2x2x2x` 一档,别指望有粗糙度字段可调(材质由模型 id 定)。

给一个模型配色时,可以顺着模型的品牌色来(Claude 系偏橙棕、GPT 系偏青绿),用户一眼就认得出手里是谁。

## 装好之后

1. 写文件 → 用户打开 **设置 → 插件 → 检视台**;
2. 在自己模型那一行的「刀皮预设」下拉里选中它 —— **选了预设,同一行的刀型/颜色控件会置灰**,因为那两项此刻由文件说了算;
3. 切到 Tangu Space,光标不在输入框里,**短按 `F`** 看一遍;长按 `F` 开详情页,能拖着转。

改完文件后重开一次设置页或详情页即可刷新(插件在这两处重读文件夹)。

## 出错了怎么看

设置页那张卡上,读不进来的文件会**逐条列出来并写明原因**(不是合法 JSON / primary 不是 `#rrggbb` / …)。别让用户去开控制台。

## 相关

- 想让刀**动**得不一样(耍法、转法、时长),那是另一件事,用技能 **检视台检视动作**(`.motion.json`)。
