# 检视台 · Forsion Inspect

像 CS 对战中那样,在**当前页面上**把手里的刀举起来耍两下 —— **不是另开一个界面**。

CS 的检视是在对战中发生的:你还看着战场,只是手上那把刀被举起来耍两下。对应到 Forsion,
「战场」就是当前 Space 页面本身。短按 F,**右下角**抽出一把刀、双手入镜耍一遍,页面原样可用。

普通刀与蝴蝶刀的切刀/检视都是照对应 **CS 真录像**逐帧对出的关键帧,不是随手编的补间。
蝴蝶刀参考视频后面重复了两遍检视,实际动画只播放其中完整的一遍。

## 两档

| 触发 | 形态 |
|---|---|
| **短按 <kbd>F</kbd>** | 铺满视口的**透明、鼠标穿透**画布。**切刀**(右下入镜 → 刀绕握把扫过掌心 → 接住 → 落成斜横持刀位,1.05s)→ **检视**(竖直看第一面 → 斜举看另一侧 → 回竖直 → 回持刀位,5.15s)→ 自动收刀。耍刀期间照常打字、点按钮,当前 Space 一点不受影响。 |
| **长按 <kbd>F</kbd>**(≈0.42s) | 全屏详情页:**品质档如实对应当前会话的思考档**,外加这个模型的最大上下文、本会话已用 token,以及换刀换手的「皮肤箱」。能拖着转、点一下重播、<kbd>Esc</kbd> 关。 |
| 命令面板 | 「检视台:耍一下刀」/「检视台:打开详情面板」两条,关掉 F 快捷键后仍可用。 |

### 品质 = 思考档(Effort)

七档思考档对七档 CS 品质,一一对应 —— 一眼看得出这一局在用多大的力气:

| Effort | `off` | `minimal` | `low` | `medium` | `high` | `xhigh` | `max` |
|---|---|---|---|---|---|---|---|
| 品质 | 消费级 | 工业级 | 军规级 | 受限 | 保密 | 隐秘 | **非凡**(金) |

宿主给不出档位(旧宿主 / 还没建会话)时那一栏写「—」,**不拿哈希编一个** —— 这一栏的全部意义
就是它如实对应你此刻的设置。同一行的「最大上下文」「本会话已用」也来自同一份实况快照。

配色仍由模型标识**哈希定死**(同一个模型永远是同一件藏品,不抽奖、不随时间变):色相由模型 id
决定,金属度/粗糙度跟着做旧程度走,模型名蚀刻在刀身上;握刀的手也是几何拼出来的。

## 模型与刀皮绑定

设置 → 插件 → 检视台下有一张逐模型绑定表:

- 刀型可选**普通刀**或**蝴蝶刀**;蝴蝶刀的两片刀柄为可动结构,使用单独的切刀/检视轨。
- 颜色可为每个模型单独指定;点「自动」即恢复从模型 ID 稳定生成的配色。
- **默认仍是普通刀 + 各种自动颜色**;只有选了蝴蝶刀或自定义色才落盘一条绑定。
- 旧版绑定的 `.glb` / `.gltf` 刀和手部模型不受影响。
- **刀皮预设**(`.skin.json`)与**检视动作**(`.motion.json`)也在这张表里逐模型绑定;选了预设,
  同一行的刀型/颜色控件置灰(那两项此刻由文件说了算)。

## 自己做刀皮和检视动作

工作文件夹(设置页第一行写着**绝对路径**,右边一颗「打开文件夹」直达)里认三种文件:

| 后缀 | 是什么 | 在哪儿选 |
|---|---|---|
| `.glb` / `.gltf` | 刀 / 手的 3D 模型 | 长按 F 的「皮肤箱」 |
| `.skin.json` | 刀皮预设(刀型 + 一对 `#rrggbb` 配色,或用 `model` 指向一个 `.glb`) | 设置页「刀皮预设」列 |
| `.motion.json` | 自定义检视动作(关键帧轨) | 设置页「检视动作」列 |

两份 JSON **都可以让 agent 代写** —— 插件随包带了两个技能:

- **检视台刀皮制作**(`skills/inspect-skin`)—— 字段表、配色手感、装到哪儿;
- **检视台检视动作**(`skills/inspect-motion`)—— 坐标系、静置位锚点、完整示例,以及两条不看就
  一定做废的规矩(整圈必须让欧拉角**累加过 2π**;`t` 必须严格递增)。

跟用户的 agent 说一句「给 Opus 做一把冰蓝色的刀」「让刀转一整圈再收」,或者把一个 `.glb` 丢给它说
「用这把」就行 —— 模型 agent 写不出来,但写一份指向它的 `.skin.json` 是它的活。

⚠️**告诉 agent 路径时用设置页第一行那个绝对路径**。云端库的本地镜像在 `~/.forsion/Amadeus Cloud/`
这样的隐藏目录里,agent 猜不到;写到别处插件看不见,而且**不报错**。

坏文件不吞:读不进来的会在设置页那张卡上**逐条列出人话原因**,动画退回内置,不会变成一片黑。

## 导入自己的模型

1. 设置 → 插件 → 检视台 → 「工作文件夹」(默认 `检视台`)。
2. 把 `.glb` / `.gltf` 放进笔记库里的那个文件夹。
3. 长按 <kbd>F</kbd> 打开详情页,左侧皮肤箱就会列出来 —— **上面一节换刀,下面一节换手**(也可以选「不画手」)。
   任意尺度的模型都会被自动归一、居中。

> 走的是宿主的 `amadeus-asset://` 协议(库内夹紧、支持 Range)。**需要带 CSP 修复的宿主 ——
> 即 2.8.1 之后的发布版,或当前 dev 构建**;已发布的 2.8.1 及更早版本的 `connect-src` 没放行
> 这个协议的 `fetch`,导入的模型读不到(会报「宿主版本过旧」;程序生成的默认皮肤不受影响)。
>
> Valve 的模型/贴图有版权,本插件不随包分发任何游戏资产;要看 CS 刀皮,请自己把文件放进工作文件夹。

## 设置

- **模型与刀皮绑定** — 逐模型选刀型、颜色、刀皮预设与检视动作;默认普通刀 + 自动色 + 内置动作。
  卡片第一行是工作文件夹的绝对路径 + 「打开文件夹」。
- **任何 Space 都能按 F** — 缺省关。开着只在 Tangu Space 生效(那里才有「当前模型」这个概念)。
- **关掉 F 快捷键** — 想把 F 留给别的用途时打开,命令面板入口保留。

## 开发

```bash
npm install
npm run verify     # typecheck + build + check(45 条静态断言,含真跑一遍的 json 校验器)
sh install.sh      # 装到 ~/.forsion-dev(缺省 dev);prod 才装 ~/.forsion
```

`main.js` 是 esbuild 打出来的单文件产物(含 three.js,约 628 KB),**已提交且必须与 `src/` 同步** ——
装包不会构建。改完 `src/` 一定重跑 `npm run build`。

### 三条宿主纪律(改代码前必读)

1. **两层的 app-region 纪律正好相反。**
   - **全屏面板**根必须 `-webkit-app-region: no-drag`,且 `document.body.appendChild`。mac 上拖窗区按
     **DOM 顺序**几何合成、与 z-index 完全无关;Shell 的 ribbon 与左侧栏是拖窗区,浮层与之重叠的
     矩形内点击/hover/滚轮会被窗口标题栏吞掉。
   - **HUD 层绝不能写 no-drag**。它落在左下角 ribbon 的拖窗区上,写了等于把那块**从拖窗区抠掉**,
     用户从此拖不动窗口。默认值 `none` 既不加也不减,正是要的。`pointer-events: none` 挡不住这条 ——
     app-region 是几何合成,与 hit-test 无关。
   两条在浏览器里都复现不了,只有真 Electron 能验。
2. **F 不能注册成宿主热键。** 宿主的 `installHotkeys` 没有输入焦点闸,绑了 `f` 会在聊天框打字时触发。
   自挂 `keydown`,守卫必须含 `e.isComposing` / `keyCode === 229`(中文输入法选字时 `e.key` 也是 `'f'`)。
3. **`ctx.tangu` 在非 Tangu 宿主上整个不存在**(纯 Amadeus 壳 / unit 设备页)→ 一律可选链。
   `check.mjs` 里有这条的负对照:把可选链拆掉必须变红。

`node check.mjs` 45 条静态断言覆盖以上全部,外加**真跑一遍**的 `.skin.json` / `.motion.json` 校验器用例;
真 DOM 那半在宿主仓:`Forsion-Genesis/desktop` 的 `npm run e2e:inspect`(29 条:两档形态、HUD 穿透与
app-region 反向纪律、面板的会话实况三行与旧宿主降级、设置交互、蝴蝶刀轨道接线、单次检视自动收刀,
**自制内容全链路 + 冷启动竞速回归**(装载时无库 → 库恢复后第一次短按 F 就得用上绑定),
含「拆掉输入态守卫必须变红」的负对照)。

### 运镜为什么不用 OrbitControls / 为什么刀手分轴

- OrbitControls 的手感(缩放、平移、阻尼)是「看模型」,不是「握着看」。这里是一条**关键帧动作**
  打在一个「手持挂点」上,相机不动。
- `viewmodel` 只做有限的腕部位移/转向;刀挂在子级 `weaponPivot` 上绕握把小幅翻面;主手与
  `weaponPivot` 同级。这样刀能吃到正反高光,主手不会跟着刀绕圈。面板拖拽也只转武器轴。
- 关键帧之间用 Euler 线性插值,但所有检视角都保持在有限范围内,**没有 2π 整圈**。参考录像本来就是
  竖直停看 → 斜举停看 → 回竖直;把角度累计到 2π 是旧版误读,不是该保留的动画技巧。
- **持刀在右、副手在左。** 副手挂在相机上,切刀时进入、检视主体段退场、结束前回来。
- 姿态数据照 CS 刺刀录像量:静置位是**斜横、刀尖朝左上 30°**,不是竖着挂。竖着挂是展台的摆法。
- 需要整体照镜子(挪到左边)时用 `mirror: true`(x 取负 + rotY/rotZ 取负),**不能用 `scale.x = -1`**
  —— 负缩放翻转法线与面剔除,金属高光当场反过来。
- 刀身蚀刻沿「刀柄→刀尖」排。**反过来排在持刀位是上下颠倒的**(放大真截图才看清,别误判成镜像)。
